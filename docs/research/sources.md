## Browser technology

- [Phaser documentation](https://docs.phaser.io/): browser-focused JS/TypeScript game framework, WebGL/Canvas support.
- [Why Phaser](https://phaser.io/why-phaser): sprites, tilemaps, audio/input, and other systems relevant to this game.
- [Phaser particles](https://docs.phaser.io/phaser/concepts/gameobjects/particles): pooled emitter features for combat effects.
- [Godot stable web-export documentation](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html): WebAssembly/WebGL 2 export, threading and hosting considerations.

Recommendation at research stage: Phaser + TypeScript, with Godot an alternative if editor/native workflows become more important. WebGL is rendering technology, not the terrain/destruction implementation. Our implementation may choose Canvas 2D for a lightweight first slice. Neither choice requires live AI inference.
